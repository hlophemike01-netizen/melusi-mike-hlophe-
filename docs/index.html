Mwhite SafeCircle

A consent-first community safety and activity PWA.

The product principle. Mwhite SafeCircle is not designed to track people. It lets people voluntarily create temporary safety activities and share their location selectively.

Three consequences run through the schema, the API authorisation, the UI and these documents: location sharing is off by default; a precise coordinate is readable only by someone the owner has authorised, while the activity is live; and precise location is temporary — ending an activity deletes its points outright.

Start here

npm install
cp .env.example .env.local     # add your Supabase URL + anon key
npx supabase link --project-ref <ref> && npx supabase db push
npm run dev

What the suites cover
SuiteCountWhat it proves
tests/db 96 Runs the real migrations on PostgreSQL + PostGIS and asserts as an ordinary signed-in user that a stranger, a non-member, an expired share and an administrator all fail to read a precise coordinate.
tests/security 102 Mounting the geolocation or push hook never prompts; no client component reaches a privileged module; the location policy has no admin escape hatch; no alert can carry a location.

What it does not do

Stated plainly, because it is part of the product

  • It does not contact emergency services. Emergency mode alerts the trusted contacts a user configured. The database column recording it defaults to false and a client cannot set it true.
  • It does not guarantee anyone's safety. It helps people share their plans with people they trust.
  • It does not track location in the background. Browsers throttle geolocation once a page is hidden, so the app stops sending rather than showing a stale point as live.
  • It does not send SMS or make calls. Contacts with an account get a push alert; anyone else gets a link the user sends themselves.
  • It has no user directory. There is deliberately no way to search for a person.

Before a public launch

  • An SMS provider, to reach trusted contacts who have no account. Web Push already covers those who do.
  • Real icons. public/icons/* are generated placeholders (npm run icons).
  • A locale-aware emergency number; the dialog currently links tel:112.
  • A nonce-based CSP, edge rate limiting on sign-in, and an independent security review.

The full list, with reasoning, is at the end of DEPLOYMENT.md.

Mwhite SafeCircle does not replace emergency services. In an emergency, call your local emergency number.
